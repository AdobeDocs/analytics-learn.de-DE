# Festlegen interner URL-Filter

In diesem Video lernen Sie die Einstellungen für Referrer kennen, indem Sie sie entweder als interne Referrer (zur Versorgung der Pfadberichte) oder als externe Referrer (zur Versorgung der Berichte zu Referrer- bzw. verweisender Domain) einstellen. Eine ausführliche Dokumentation finden Sie unter [Interne URL-Filter](https://experienceleague.adobe.com/docs/analytics/admin/admin-tools/internal-url-filter-admin.html?lang=de){target="_blank"}.

>[!VIDEO](https://video.tv.adobe.com/v/333043/?quality=12&learn=on)

>[!NOTE]
>
>Wenn Sie einen Wert in interne URL-Filter eingeben, kopieren Sie ihn nicht aus einer Liste in Programmen wie Microsoft Excel. Es besteht die Gefahr, unsichtbare, irrelevante Zeichen zu kopieren und einzufügen. Bitte aus einem Texteditor kopieren, in dem alle Zeichen angezeigt werden, oder den Wert manuell in das Feld eingeben.
