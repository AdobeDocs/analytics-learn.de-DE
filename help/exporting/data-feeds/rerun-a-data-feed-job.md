# Erneutes Ausführen eines Daten-Feed-Auftrags

Die Daten-Feed-Benutzeroberfläche in Adobe Analytics erleichtert die Verwaltung von Daten-Feeds erheblich. Wenn Sie Zugriff auf die Verwaltung von Daten-Feeds haben, können Sie selbst einen Daten-Feed-Vorgang in der Daten-Feed-Benutzeroberfläche erneut ausführen, ohne dass das Support-Team die Daten-Feed-Dateien erneut senden muss.
